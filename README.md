## Sobre o Projeto

O **FLORA** é um projeto desenvolvido com o objetivo de praticar conceitos de:

- Estruturação HTML5
- CSS Moderno
- Flexbox
- CSS Grid
- Responsividade
- Design UI/UX
- Landing Pages Comerciais

> O projeto simula uma marca premium de cosméticos focada em skincare, maquiagem e cuidados com a pele.
